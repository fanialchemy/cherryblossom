CHERRYBLOSSOM — Proyek Pemrograman Web 1

CARA MEMBUKA
Ekstrak seluruh ZIP, lalu buka index.html di browser. Tidak perlu instalasi,
Node.js, npm, backend, atau database. Bootstrap 5.3.9, font, dan semua gambar
disertakan lokal sehingga situs tetap tampil walau offline (kecuali peta
Google Maps di kontak.html yang membutuhkan internet).
Untuk penyimpanan keranjang paling konsisten antarhalaman, gunakan hosting
statis atau ekstensi Live Server di editor. Perilaku localStorage pada file://
berbeda antarbrowser. Situs tetap dapat dibuka langsung untuk peninjauan.

TEKNOLOGI
HTML5, CSS3, JavaScript dasar, dan Bootstrap 5.3.9 (offline).
- Tata letak memakai grid Bootstrap (container, row, col-*, g-*) dan utility
  Bootstrap (d-flex, py-5, mb-4, text-center, d-none d-md-inline, dll.).
- Komponen Bootstrap: navbar, carousel, card, badge,
  btn / btn-sm rounded-pill, breadcrumb, table table-striped, form-control,
  form-select, form-check, modal, dropdown, accordion.
- Hiasan awan & kelopak hanya di hero, kartu kategori, banner promo, dan
  cerita singkat; disembunyikan di HP dengan class "d-none d-md-block".
- Ikon tas belanja "bag-heart" (navbar) dan kaca pembesar "search" (kolom
  pencarian produk.html) dari Bootstrap Icons (MIT), disalin sebagai inline
  SVG (tanpa library tambahan).
- css/style.css hanya mengatur warna, huruf, sudut bulat, bayangan, dan hiasan.
- js/script.js memakai function biasa, for loop, dan localStorage.
Tidak ada framework aplikasi, proses build, atau permintaan API.

DELAPAN HALAMAN & FITUR
index.html     : urutan section: carousel Bootstrap 5 slide (berganti
                 setiap 3,5 detik, tombol prev/next, 5 titik indikator)
                 -> 4 kartu keunggulan -> kartu kategori Anak & Dewasa
                 -> 8 produk favorit -> "Cara belanja" (3 langkah dalam
                 panel putih) -> banner promo "Voucher Gemes!" (kode
                 contoh BLOSSOM10, promo simulasi) -> cerita singkat.
                 Semua section memakai latar pink lembut yang sama, py-5.
panduan-ukuran.html : 2 kolom (col-md-6). Kiri: tabel ukuran dewasa 36–40
                 lalu cara mengukur kaki (<ol> 4 langkah). Kanan: tabel
                 ukuran anak 24–34 lalu tips memilih ukuran (<ul>). Tabel
                 memakai table-striped dengan belang pink muda. Ditautkan
                 dari footer semua halaman, detail.html (di dekat pilihan
                 ukuran), kartu langkah 2 "Cara belanja", dan kontak.html.
Semua halaman  : header menempel saat di-scroll; menu aktif berbentuk pill
                 pink; menu "Koleksi" berupa dropdown (Semua koleksi, Koleksi
                 anak, Koleksi dewasa, Panduan ukuran); kolom "Cari produk..."
                 yang membuka produk.html?cari=...; tombol keranjang dengan ikon tas (di HP hanya ikon +
                 angka); footer berisi link "Panduan ukuran" dan baris
                 bawah "Dibuat dengan sepenuh hati ♡".
produk.html    : katalog 16 produk (card + grid), filter kategori
                 (Semua/Anak/Dewasa), filter jenis (Semua/Sepatu/Sandal),
                 dan pencarian nama. Filter bisa dibuka dari URL,
                 contoh produk.html?kategori=Anak.
detail.html    : detail produk diisi JavaScript dari ?id= di URL
                 (contoh detail.html?id=sakura-puni), breadcrumb, pilihan
                 ukuran + link "Bingung ukuran? Lihat panduan ukuran",
                 jumlah, tambah ke keranjang, kotak "Bahan & perawatan"
                 di bawah foto (diisi dari field material & care).
keranjang.html : daftar belanja, ubah jumlah (1–10), hapus barang,
                 total Rupiah, dan tombol "Lanjut ke pengiriman" ke
                 checkout.html (disembunyikan jika keranjang kosong).
checkout.html  : penanda langkah (1 Keranjang - 2 Pengiriman - 3 Selesai),
                 form "Data pengiriman" (nama, nomor HP, alamat, metode
                 pembayaran, catatan) yang divalidasi atribut HTML, dan
                 kartu "Ringkasan pesanan" dari keranjang. Setelah "Buat
                 pesanan": keranjang dikosongkan, angka navbar jadi 0, dan
                 pop-up (Modal Bootstrap) "Pesanan berhasil!" muncul.
                 Jika keranjang kosong, form diganti pesan kosong.
tentang.html   : kolase foto produk + cerita merek, tiga nilai merek,
                 tombol "Jelajahi koleksi", dan penjelasan proyek.
kontak.html    : FAQ 5 pertanyaan (Accordion Bootstrap, satu terbuka
                 sekaligus), formulir (required, email, minlength,
                 checkbox promo opsional) dengan
                 validasi tambahan JavaScript dan pop-up (Modal Bootstrap)
                 "Pesan terkirim!"; section "Kunjungi toko kami"
                 berisi alamat, jam buka, nomor contoh, dan peta Google Maps.

MENGGANTI FOTO
Setiap produk punya file gambar sendiri di images/produk/ dengan nama sesuai id
(misalnya images/produk/sakura-puni.jpg). Gambar carousel ada di
images/banner/hero-1.jpg sampai hero-5.jpg. Cukup timpa file dengan foto baru
bernama SAMA (format .jpg), tidak perlu mengubah kode. Foto tampil dengan
warna asli (tanpa efek warna) dan dipotong rapi menjadi persegi (object-fit:
cover), jadi letakkan produk di tengah foto.
Logo navbar & footer ada di images/logo.png. Timpa dengan logo baru bernama
SAMA; tingginya diatur CSS (44px navbar, 40px footer), lebarnya mengikuti
proporsi gambar, jadi logo persegi maupun memanjang tetap tampil rapi.

ALUR KERANJANG
Data produk ada di awal js/script.js. Harga tidak diambil dari input pengunjung.
Keranjang menyimpan id produk, ukuran, dan jumlah dalam localStorage
(kunci "cherry-cart"). Jumlah dibatasi 1–10 pasang per produk/ukuran.
Tombol "Buat pesanan" tidak memproses transaksi nyata. Form kontak tidak mengirim atau
menyimpan data.

CATATAN KONTEN
CHERRYBLOSSOM adalah merek fiktif. Nama, harga, ukuran dan deskripsi produk
merupakan contoh akademik. Maskot, awan, dan kelopak digambar sendiri (SVG).
