CHERRYBLOSSOM — Proyek Pemrograman Web 1

CARA MEMBUKA
Ekstrak seluruh ZIP, lalu buka index.html di browser. Tidak perlu instalasi,
Node.js, npm, backend, atau database. Bootstrap 5.3.9, font, dan semua gambar
disertakan lokal (offline), jadi situs tetap tampil tanpa internet, kecuali
peta Google Maps di kontak.html.
Untuk penyimpanan keranjang paling konsisten antarhalaman, gunakan hosting
statis atau ekstensi Live Server di editor. Perilaku localStorage pada file://
berbeda antarbrowser. Situs tetap dapat dibuka langsung untuk peninjauan.

TEKNOLOGI
HTML5, CSS3, JavaScript dasar, dan Bootstrap 5.3.9 (offline, tanpa CDN).
- Tata letak memakai grid Bootstrap (container, row, col-*, g-*) dan utility
  Bootstrap (d-flex, gap-*, py-5, mb-4, text-center, d-none d-md-block, dll.).
- Komponen Bootstrap yang dipakai:
  navbar + collapse (menu hamburger di HP), dropdown (menu "Koleksi"),
  carousel (hero beranda & slider foto detail), card (kartu produk),
  grid, form (form-control, form-select, form-check), badge, breadcrumb,
  table (table-striped), accordion (FAQ kontak), modal (pop-up berhasil),
  serta btn / rounded-pill.
- Ikon dari Bootstrap Icons (MIT), disalin sebagai inline SVG tanpa library
  tambahan: "bag-heart" (tombol keranjang), "search" (kolom pencarian),
  dan "instagram" (link Instagram).
- Hiasan awan & kelopak (images/dekor/) dipakai di hero, kartu kategori,
  banner promo, cerita singkat, dan kotak "Kunjungi toko kami"; disembunyikan
  di HP dengan class "d-none d-md-block".
- css/style.css mengatur warna, huruf, sudut bulat, bayangan, dan hiasan.
- js/script.js memakai function biasa, for loop, dan localStorage.
Tidak ada framework aplikasi, proses build, atau permintaan API.

8 HALAMAN HTML & FITUR
Semua halaman  : header menempel saat di-scroll; logo (images/logo.png) +
                 nama "Cherry Blossom" + slogan "STEP INTO CUTE COMFORT";
                 menu aktif berbentuk pill pink; menu "Koleksi" berupa
                 dropdown (Semua koleksi, Koleksi anak, Koleksi dewasa,
                 Panduan ukuran); kolom "Cari produk..." yang membuka
                 produk.html?cari=...; tombol keranjang bulat berisi ikon tas
                 dan angka jumlah barang (badge). Di HP menu masuk ke tombol
                 hamburger. Footer berisi link Jelajahi (Semua koleksi, Cerita
                 kami, Keranjang belanja), Ada pertanyaan? (Hubungi kami,
                 Panduan ukuran, Instagram @cherryblossom), dan baris bawah
                 "© 2026 CHERRYBLOSSOM" serta "Dibuat dengan sepenuh hati ♡".
index.html     : carousel hero 5 slide (berganti setiap 3,5 detik, tombol
                 prev/next, 5 titik indikator; gambar PNG transparan)
                 -> 4 kartu keunggulan -> kartu kategori Anak & Dewasa
                 -> 8 produk favorit -> "Cara belanja" (3 langkah)
                 -> banner promo "Voucher Gemes!" (kode BLOSSOM10)
                 -> cerita singkat.
produk.html    : katalog 16 produk (card + grid). Satu panel berisi filter
                 kategori (Semua/Anak/Dewasa, pink), filter jenis
                 (Semua/Sepatu/Sandal, biru), dan pencarian nama. Filter dan
                 pencarian bisa dibuka dari URL, contoh
                 produk.html?kategori=Anak atau produk.html?cari=sakura.
detail.html    : isi diambil JavaScript dari ?id= di URL (contoh
                 detail.html?id=sakura-puni): breadcrumb, nama, harga,
                 deskripsi, warna, pilihan ukuran + link "Bingung ukuran?
                 Lihat panduan ukuran", jumlah, dan tombol tambah ke keranjang.
                 Produk dengan lebih dari satu foto tampil sebagai slider
                 (Carousel Bootstrap, berganti otomatis setiap 4 detik,
                 berhenti saat kursor di atas foto). Di bawah foto ada kotak
                 "Bahan & perawatan".
keranjang.html : daftar belanja, ubah jumlah (1–10), hapus barang, ringkasan
                 total Rupiah, dan tombol "Lanjut ke pengiriman" ke
                 checkout.html (disembunyikan jika keranjang kosong).
checkout.html  : penanda langkah (1 Keranjang - 2 Pengiriman - 3 Selesai),
                 form "Data pengiriman" (nama, nomor HP, alamat, metode
                 pembayaran, catatan) yang divalidasi atribut HTML (required,
                 pattern, minlength), dan kartu "Ringkasan pesanan". Setelah
                 "Buat pesanan": keranjang dikosongkan, angka di navbar jadi 0,
                 dan pop-up (modal) "Pesanan berhasil!" muncul. Jika keranjang
                 kosong, form diganti pesan "Keranjangmu masih kosong".
tentang.html   : kolase 3 foto produk, kutipan, cerita merek, tiga nilai
                 merek, tombol "Jelajahi koleksi", dan keterangan bahwa
                 CHERRYBLOSSOM adalah merek fiktif untuk proyek ujian.
kontak.html    : FAQ 5 pertanyaan (accordion, satu terbuka sekaligus);
                 formulir (nama, email, topik, pesan, checkbox persetujuan
                 wajib) dengan validasi HTML + JavaScript dan pop-up (modal)
                 "Pesan terkirim!"; kotak "Kunjungi toko kami" berisi alamat,
                 jam buka, telepon, email, Instagram, dan peta Google Maps.
panduan-ukuran.html : 2 kolom. Kiri: tabel ukuran dewasa 36–40 lalu cara
                 mengukur kaki (4 langkah). Kanan: tabel ukuran anak 24–34
                 lalu tips memilih ukuran. Tabel memakai table-striped dengan
                 belang pink muda. Ditautkan dari dropdown "Koleksi", footer,
                 detail.html, langkah 2 "Cara belanja", dan FAQ kontak.

MENGGANTI FOTO
- Foto produk: images/produk/<id>.jpg (misalnya sakura-puni.jpg). Foto ini
  dipakai di kartu produk, keranjang, dan checkout.
- Foto tambahan untuk slider di detail.html: <id>2.jpg, <id>3.jpg, lalu
  daftarkan di array "images" produk tersebut di js/script.js (foto utama
  selalu di urutan pertama). Saat ini 15 dari 16 produk punya 2–3 foto;
  Niji Pyon hanya 1 foto, jadi tampil sebagai gambar biasa.
- Gambar carousel beranda: images/banner/hero-1.png sampai hero-5.png
  (PNG transparan, tampil utuh dengan object-fit: contain).
- Logo: images/logo.png. Tingginya diatur CSS (44px navbar, 38px di HP,
  40px footer) dan lebarnya mengikuti proporsi gambar.
Cukup timpa file dengan nama yang SAMA (produk .jpg, banner .png), tidak perlu
mengubah kode. Foto produk tampil dengan warna asli dan dipotong rapi menjadi
persegi (object-fit: cover), jadi letakkan produk di tengah foto.

ALUR KERANJANG
1. detail.html: pilih ukuran & jumlah -> "Tambahkan ke keranjang".
2. keranjang.html: ubah jumlah atau hapus barang -> "Lanjut ke pengiriman".
3. checkout.html: isi data pengiriman -> "Buat pesanan" -> pop-up berhasil,
   keranjang kosong.
Keranjang disimpan di localStorage (kunci "cherry-cart") berisi id produk,
ukuran, dan jumlah. Harga selalu diambil dari data produk, bukan dari input
pengunjung. Jumlah dibatasi 1–10 pasang per produk/ukuran.
Tidak ada pembayaran atau pengiriman nyata, dan form kontak tidak mengirim
maupun menyimpan data.

CATATAN KONTEN
CHERRYBLOSSOM adalah merek fiktif untuk proyek ujian Pemrograman Web 1.
Nama, harga, ukuran, deskripsi produk, dan data kontak merupakan contoh.
Maskot, awan, dan kelopak digambar sendiri (SVG).
