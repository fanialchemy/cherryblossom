CHERRYBLOSSOM — Proyek Pemrograman Web 1

CARA MEMBUKA
Ekstrak seluruh ZIP, lalu buka index.html di browser. Tidak perlu instalasi,
Node.js, npm, backend, atau database. Bootstrap 5.3.3, font, dan semua gambar
disertakan lokal sehingga situs tetap tampil walau offline.
Untuk penyimpanan keranjang paling konsisten antarhalaman, gunakan hosting
statis atau ekstensi Live Server di editor. Perilaku localStorage pada file://
berbeda antarbrowser. Situs tetap dapat dibuka langsung untuk peninjauan.

TEKNOLOGI
HTML5, CSS3, JavaScript dasar, dan Bootstrap 5.3.3 (offline).
- Tata letak memakai grid Bootstrap (container, row, col-*, g-*) dan utility
  Bootstrap (d-flex, py-5, mb-4, text-center, dll.).
- Komponen Bootstrap: navbar, carousel, card, badge rounded-pill, btn,
  breadcrumb, form-control, form-select, form-check.
- css/style.css hanya mengatur warna, huruf, sudut bulat, bayangan, dan hiasan.
- js/script.js memakai function biasa, for loop, dan localStorage.
Tidak ada framework aplikasi, proses build, atau permintaan API.

ENAM HALAMAN & FITUR
index.html     : header menempel saat di-scroll; carousel Bootstrap 5 slide
                 (berganti setiap 3,5 detik, tombol prev/next dan 5 titik
                 indikator); 4 label keunggulan; 8 produk unggulan; kartu
                 kategori Anak & Dewasa; cerita singkat.
produk.html    : katalog 16 produk (card + grid), filter kategori
                 (Semua/Anak/Dewasa), filter jenis (Semua/Sepatu/Sandal),
                 dan pencarian nama. Filter bisa dibuka dari URL,
                 contoh produk.html?kategori=Anak.
detail.html    : detail produk diisi JavaScript dari ?id= di URL
                 (contoh detail.html?id=sakura-puni), breadcrumb, pilihan
                 ukuran, jumlah, tambah ke keranjang, panduan ukuran.
keranjang.html : daftar belanja, ubah jumlah (1–10), hapus barang,
                 total Rupiah, dan tombol simulasi selesai.
tentang.html   : cerita merek, tiga nilai merek, dan penjelasan proyek.
kontak.html    : formulir (required, email, minlength, checkbox) dengan
                 validasi tambahan JavaScript.

Setiap halaman memuat css/bootstrap.min.css, css/style.css (yang mengimpor
fonts.css), js/bootstrap.bundle.min.js, dan js/script.js. Header/footer disalin
sama pada tiap halaman agar mudah dipelajari. Hiasan dipanggil dengan
<img src="images/dekor/...svg" alt="" aria-hidden="true">.

MENGGANTI FOTO
Setiap produk punya file gambar sendiri di images/produk/ dengan nama sesuai id
(misalnya images/produk/sakura-puni.jpg). Gambar carousel ada di
images/banner/hero-1.jpg sampai hero-5.jpg. Saat ini isinya masih foto
contoh. Cukup timpa file dengan foto baru bernama SAMA (format .jpg), tidak
perlu mengubah kode.

ALUR KERANJANG
Data produk ada di awal js/script.js. Harga tidak diambil dari input pengunjung.
Keranjang menyimpan id produk, ukuran, dan jumlah dalam localStorage
(kunci "cherry-cart"). Jumlah dibatasi 1–10 pasang per produk/ukuran.
Tombol simulasi tidak memproses transaksi. Form kontak tidak mengirim atau
menyimpan data.

CATATAN KONTEN
CHERRYBLOSSOM adalah merek fiktif. Nama, harga, ukuran dan deskripsi produk
merupakan contoh akademik. Foto pihak ketiga hanya sebagai ilustrasi, bukan
bukti produk milik merek CHERRYBLOSSOM. Sebelum penggunaan komersial, gunakan
foto sendiri atau foto berlisensi yang sesuai. Maskot, awan, dan kelopak
digambar sendiri (SVG).
