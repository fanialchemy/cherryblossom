CHERRYBLOSSOM — Proyek Pemrograman Web 1

CARA MEMBUKA
Ekstrak seluruh ZIP, lalu buka index.html di browser. Tidak perlu instalasi,
Node.js, npm, backend, atau database. Bootstrap 5.3.3 dan foto disertakan lokal.
Font Fredoka dan Nunito disertakan lokal sehingga tampilan font tetap tersedia offline.
Untuk penyimpanan keranjang paling konsisten antarhalaman, gunakan hosting
statis atau ekstensi Live Server di editor. Perilaku localStorage pada file://
berbeda antarbrowser. Situs tetap dapat dibuka langsung untuk peninjauan.

ENAM HALAMAN
index.html: beranda dengan Bootstrap carousel dua slide dan 8 produk unggulan.
produk.html: katalog 16 produk (Bootstrap card + grid), filter Semua/Anak/Dewasa,
             filter Sepatu/Sandal, dan pencarian sederhana.
detail.html: detail produk (diisi JavaScript dari ?id= di URL), pilihan ukuran,
             dan tambah ke keranjang.
keranjang.html: ubah jumlah, hapus produk, total Rupiah, dan simulasi selesai.
tentang.html: cerita merek serta penjelasan proyek.
kontak.html: formulir dengan required, email, minlength, dan validasi sederhana.

Setiap halaman memuat css/bootstrap.min.css, css/style.css (yang mengimpor
fonts.css), js/bootstrap.bundle.min.js, dan js/script.js. Header/footer disalin
secara konsisten pada tiap halaman agar mudah dipelajari. Tidak ada router,
framework aplikasi, proses build, atau permintaan API.

MENGGANTI FOTO PRODUK
Setiap produk punya file gambar sendiri di images/produk/ dengan nama sesuai id
(misalnya images/produk/sakura-puni.jpg). Saat ini isinya masih salinan foto
sumber. Cukup timpa file dengan foto baru bernama SAMA (format .jpg), tidak
perlu mengubah kode. Gambar carousel beranda diganti di images/banner/.

ALUR KERANJANG
Data produk ada di awal js/script.js. Harga tidak diambil dari input pengunjung.
Keranjang menyimpan ID produk, ukuran dan jumlah dalam localStorage.
Jumlah dibatasi 1–10 pasang per produk/ukuran. Tombol simulasi tidak memproses
transaksi. Form kontak tidak mengirim atau menyimpan data.

CATATAN KONTEN
CHERRYBLOSSOM adalah merek fiktif. Nama, harga, ukuran dan deskripsi produk
merupakan contoh akademik. Foto pihak ketiga hanya sebagai ilustrasi, bukan
bukti produk milik merek CHERRYBLOSSOM. Sebelum penggunaan komersial, gunakan
foto sendiri atau foto berlisensi yang sesuai.
